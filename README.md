# Tableau Data Storytelling Portfolio

Three projects from Columbia University's **APAN 5800: Storytelling with Data and AI** (Fall 2025). Each one turns data into an interactive Tableau story with a clear business or policy recommendation.

| Project | Question | Result |
| --- | --- | --- |
| [Sotol Hacienda US Expansion](sotol-us-expansion/) (team) | Where should a premium spirits brand expand next in the US? | **1st place of 8 teams.** Recommended NYC, based on a 7-dashboard story across 388 venues |
| [AI Stocks Dashboard](ai-stocks-dashboard/) | How did NVIDIA and Microsoft react to AI news vs. the S&P 500? | Interactive dashboard linking volume and price spikes to earnings events |
| [US Child Poverty Maps](child-poverty-maps/) | Where should UNICEF focus child poverty interventions? | 15-year choropleth story (2007–2022) showing persistent concentration in Southern states |

**Skills:** Tableau (dashboards, story points, maps, dashboard actions), data cleaning, market segmentation, KPI design, executive presentation

## How to open the workbooks

Open any `.twbx` file with [Tableau Desktop](https://www.tableau.com/products/desktop) or the free [Tableau Public](https://public.tableau.com/app/discover) app. The data is packaged inside each file.
